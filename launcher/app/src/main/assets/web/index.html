安装与启动

不用再拔 U 盘

歌曲从电脑直接写入电视上插着的 U 盘，不占用电视内部存储。上传完成后，在 Chora 重新扫描本地歌曲。

保存位置：U盘 /Music/极简桌面上传。同名文件自动编号，不覆盖已有歌曲。

电视调试连接

首次点击连接后，在电视弹窗勾选“始终允许”并确认。之后安装、卸载、实时画面和输入源控制可独立运行。
