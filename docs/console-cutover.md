## 验收记录与边界

- 0.3.3 控制台迁移包：90 项真实 HTTP/接口检查通过，11 页各刷新 20 次通过；另四页因等待独立浏览器登录，尚未完成 20 次刷新。
- 手机浏览器由用户确认正常打开且不闪旧页。1280/1440/1920 实际素材网格分别为3/4/5列。
- 原生一项外观设置完成修改、回读、恢复；受保护应用拒绝卸载、待机缺少确认拒绝执行；网页待机确认取消通过。
- 实时画面与网页 Home 操作通过。未执行删除正式日志、卸载正式应用、全新安装、真实回退等破坏性验证。
- 1.0.0：中国城市库使用 GeoNames CC BY 4.0 数据；耒阳、衡阳、拼音与市后缀测试通过。更新页共用组件保留标题ID，开关草稿不会被轮询覆盖；保存后回读。
- 首次无密码选择仅对未设置访问方式的设备开放，先提示确认；已有账号不开放此入口。关闭无密码模式需要有效账号密码。
- 不将模拟预览、接口200或安装任务排队视为电视安装成功。新版在盒子上的实际在线升级由用户执行。
- icons、themes/upload、ai/chat 预留接口返回 NOT_IMPLEMENTED。指定任意历史版本下载安装尚未接入新页；受管上一版本回退继续保留。

完整字段盘点见 console-feature-map.json。
