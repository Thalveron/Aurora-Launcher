# 控制台改版：第 1 步验收

验收展示文件位于 `launcher/tools/console-preview/`，仅由本地开发服务提供，不进入 APK。

本阶段只建立外壳和共用组件，不重排天气、屏保或其他页面的内容，不改原生接口、登录保护、上传和安装逻辑，不打包 APK。

## 入口清单

| 分组 | 页面 | 原路由锚点 |
| --- | --- | --- |
| 外观 | 主题管理、当前主题设置、背景库 | themes / legacy / background |
| 内容 | 全局屏保、应用管理、U 盘歌曲上传、语言与朗读 | saver / library / usb / language |
| 设备 | 连接与输入源、桌面预览、应用流量监控、遥控与设备 | inputs / capture / traffic / device |
| 系统 | 天气与时间服务、桌面更新、安全设置、操作日志 | services / updates / security / logs |

共 15 个唯一入口，分组数量为 3 / 4 / 4 / 4。当前主题的 style / layout / music / advanced 子页及 assets 上传辅助页保留原入口和处理器。

## 共用组件

- `assets/aurora/console/shell.css`：所有新组件的设计令牌和样式；正文 14px、说明 12px、8px 网格、12px 圆角、设置行最小高度 52px（说明换行时自动增高）。深浅色共用变量；保留键盘焦点和减少动效偏好。
- `shell.js`：生成统一导航和顶栏，显示当前主题、在线与同步状态。实时画面仍走现有 `/api/v1/system/screen.mjpeg?fps=1`，用户主动展开后才请求，收起、离开页面或页面不可见时停止。
- `AuroraConsoleUI.row(name, description, control)` 与 `.card(title, description, rows)`：后续两页复用这些构造方法，禁止分别再写一套布局样式。
- `.draft(id, {initial, label, render, validate, save, discard})`：草稿管理。`set` / `patch` 仅修改草稿；所有组先校验再按顺序保存。已成功写入的组标记为已保存，失败及未执行的组保留草稿，重试不重复提交成功项。撤销不提交写入；保存期间防止重复提交；关闭页面提醒未保存更改。
- 新草稿管理尚未接管其他页面的即时保存。天气、屏保在第 2 步接入；其余在第 3 步逐页迁移，避免静默改动既有功能。

- 当前主题及应用/USB/日志的原生嵌入页仍有功能依赖，不能直接删除。保留隐藏后加载和 section-ready 检查；本地 mock 不递归打开真实控制台嵌入页。

## 第 2 步样板：天气与时间服务

已按用户后续指示先完成天气与时间服务；全局屏保暂未迁移。

- 验收入口：`http://127.0.0.1:8770/console/settings.html?mock=1#services`。这次是完整功能表单，不是第一步的控件示例。
- `services-page.js` 负责页面，复用 `shell.js` 的设置行、卡片和草稿事务；`services-model.js` 负责无副作用的数据整理与校验。原 `settings.js` 中重复的服务表单和轮询已移除，其他页面保留原行为，包括音乐设置仍使用的 `lines()` 辅助方法。
- 城市搜索、地区选择、IANA 时区、手动经纬度、天气解析器、服务密钥、刷新间隔、地址与备用顺序、请求头、六项 JSONPath 映射、NTP、备用 HTTPS Date、校时间隔、系统时间权限开关都已保留。
- 高级坐标、天气地址/映射、时间地址默认折叠。正文与说明共用令牌，主内容最大 720px；本页只有底部保存按钮使用主强调色。
- 编辑、选择模板、恢复默认均只修改草稿；保存继续使用既有 `POST /api/v1/services`，原生层继续处理空地址的默认回退、全局城市与时区和自动刷新。测试继续用 `POST /api/v1/services/test`，明确测试已保存配置。
- `POST /api/v1/services/reset` 原接口保持不变；新 UI 将默认值放入草稿，确认保存后通过现有保存接口提交，避免绕开保存／撤销。
- 模板保留 Open-Meteo 和和风天气；切换模板保留城市。和风占位 API Host 必须替换后才能提交。仅 HTTPS；JSON、地址数量、NTP、刷新间隔和城市坐标先在前端校验，原生校验仍保留。
- 本地 mock 增加已存在服务接口的保存、测试和重置模拟，并提供部分城市示例；不向外部服务发请求，不改变真实 API 格式或设备设置。
